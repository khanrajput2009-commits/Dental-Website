# Dental Clinic Website 🦷

A modern, clean, and responsive website for a Dental Clinic built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
Check out the live website here: 
[https://khanrajput2009-commits.github.io/Dental-Website/](https://khanrajput2009-commits.github.io/Dental-Website/)

---

## ✨ Features
* **Modern UI:** Clean, professional, and user-friendly design.
* **Services Showcase:** Display of various dental care services offered.
* **Appointment Booking:** Interactive section for booking patient appointments.
* **Fully Responsive:** Optimized for both mobile devices and desktop screens.

---

## 🛠️ Technologies Used
* **HTML5** - Structure and semantic content
* **CSS3** - Styling and responsive layouts
* **JavaScript** - Interactive elements and features
